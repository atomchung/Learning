# 正確性由機器把關，不進人的偏好迴圈

**一句話**：當一個系統唯一會回饋進改版的訊號是**人的偏好排序**，正確性檢查若跑在排序**之後**，它就永遠影響不了系統的演化方向——系統會單向往「更會說服」而不是「更不會講錯」走；解法不是把檢查做得更強或更全，而是把它**移到人看到答案之前**，並且交給機器而不是靠模型自律。

## 為什麼是「位置」這個軸

已有兩張卡各管一個軸，這張補第三個：

- **強度軸**：[verifier-is-a-ladder-not-a-switch](./verifier-is-a-ladder-not-a-switch.md) — 驗證訊號站在階梯哪一階
- **覆蓋軸**：[one-sided-checks-drift-the-system](./one-sided-checks-drift-the-system.md) — 檢查只設單側，系統往單側漂
- **位置軸（這張）**：檢查跑在迴圈的哪一步

**跑在人的判斷之後，再強再全都等於沒跑。** 因為改版的輸入是人的排序，而排序做成的當下，檢查結果還不存在。

## 證據：一次四答案盲評

同一個問題、同一份凍結資料、四個獨立產生的答案，人盲評排序；另一個獨立 agent 事後把四則的每一條事實宣稱回溯核對同一份資料。

**兩個結果並讀才看得出問題**：排第一那則的核心類比，在承重的那個數字上方向反了（把減速寫成加速，而整條論證需要「加速」才成立）；排最後那則的引用準確率是四則最高，且是唯一主動聲明自己兩個數字口徑不同、不可互換的。

**排序與正確性正交。** 而排序是唯一會變成下一輪改動的訊號——所以每一輪都在把答案推向更篤定、更完整的敘事，不是更不會講錯。這個方向是機制保證的，不是偶然。

## 機器 gate 的射程有多遠（這條決定它能不能落地）

同一次稽核裡，91 條宣稱只有 54 條可判定，其餘 37 條落在「本地資料裡找不到對照物」——那些是外部抓來的事實。

所以這張卡的射程是**有對照物的宣稱**：
- **能機械 gate**：宣稱與自己既有記錄衝突（同一事件、同一來源，兩處數字打架）
- **gate 不到**：全新的外部事實，本地沒有任何東西可以對照

推論一：**先 gate 有對照物的那半**，不要因為蓋不全就不做——承重的類比通常引的正是自己記過的事件（沒記過的東西當事人不熟，本來就不會拿來當支點）。

推論二：**規則要有機制才算數**。同一次觀察的另一半：被機械強制的限制（數字只能來自引擎、外部事實必須帶來源）換來的是實測最高的準確率；只靠一句「不准做 X」的限制換來的是模型往最保守端塌陷、什麼都不說。**能機械化的就機械化，不能機械化的就別寫成規則靠自律。**

## 反例與質疑

- **前移會污染偏好測量**：人看到「這條與記錄相反」的標記後，排序就不再是純粹的偏好資料。若目的是研究偏好，這是真代價；若目的是把產品做對，這正是要的效果。**先問這個迴圈是要測人還是要修產品。**
- **不是所有正確性都有 ground truth**：開放式判斷、預測、品味沒有對照物，硬做 gate 會退化成形式檢查。這張卡只管可回溯的事實宣稱。
- **存在性檢查會給假通過**：驗收若只問「有沒有出現價值／關聯／反面／下一步」，一個四項全過的答案仍可能是同場最差的——存在性判準看不見說服力，也看不見準確性。

## 我原本以為的、錯在哪

原本把這件事描述成現象（「系統會往更會說服演化」），停在觀察層。使用者的修正是解法層：**正確性交給機器把關、不依賴人判斷**——同一個發現，一個是描述，一個能直接改設計。**採用他的措辭**（前例：2026-07-20 他把我的內部術語換成「關注前沿的認知且能幫助更好的決策」，也比我的準）。

同一場還踩了第二個坑：讀產品規格時看到一句禁令就推論「它禁止論述」，實際上那句的主詞是另一條路線，該路線明文**要求**做正反論證。**歸屬錯誤，與 2026-08-10 那次同型**（把「市場擔心 X」讀成「某公司說 X」）——看到一句話先確認主詞是誰，第二次犯。
