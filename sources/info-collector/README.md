# info_collector 閱讀入口

每日材料按 `YYYY-MM-DD.md` 命名，先看最新日期，再按問題找關聯。每份最多三則學習候選與三則個人 AI 專案線索；不是每日待辦。

## 怎麼使用

1. 有疑問時，沿材料裡的既有卡／筆記連結讀上下文，再回原文核對。
2. 選一條會影響當前決策的材料，一起討論它改變什麼、證據夠不夠。
3. 實際理解先留在 [notes](../../notes/)，能跨情境重用時再升卡；沒讀過的材料不寫成「我學會了」。

週綜合仍是手動；只回看實際討論過的判斷。專案研究接 [既有 GTM](../../topics/ai-project-research/gtm/README.md)，不是另建一套筆記系統。

## 證據與保存界線

info_collector 保存收錄欄位、摘錄與生成摘要，並非所有來源的完整原文。日報編號能回查文章；全文、論文細節、作者自報需另核。

材料裡的關聯是字詞相關候選，可能漏抓或抓錯，不代表語意上的支持或反駁。商業線索是個案或自述，沒有查到的 buyer/payment/retention 保持 unknown。

本 Learning repo 公開；producer 只放公開來源的選讀入口。SQLite、個人回信標記與偏好歷史保存在 private info-collector repo，環境設定與憑證不入 Git。

同一天材料固定，不因補跑改寫。更新理解寫 notes；回到當日材料時仍能辨認當時的 Learning SHA、來源日期和收錄日期。
